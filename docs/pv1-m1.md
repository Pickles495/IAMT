# M1 Preview検証

現行デモと個人ワークスペースは別の保存領域を使う。既存データは自動転送しない。
個人ワークスペースは /workspaces。招待済みユーザーでログインすると、Topic、複数のBoardと会話の作成・復元、Topic名変更ができる。セッションはメモリに保持し再読み込み時は再ログインする。
隔離された開発用Supabaseプロジェクトでマイグレーションを一度適用し、Preview用環境変数 SUPABASE_URL と SUPABASE_PUBLISHABLE_KEY を設定する。公開サインアップは無効にし、招待ユーザーのパスワードを設定する。サービスロールキーを使用しない。
PostgreSQLのRLSと複合外部キーが所有者を検証する。Topic作成・初期Board・初期会話・イベントは同一トランザクション。Structureジョブの構築と構造化応答の検証には差し替え可能なテスト用transportを使う。OpenAIの実呼出しはM2。
npm test は組込みPostgresでマイグレーションを実行し、異なる二つの認証IDで読み書きを試す。実Supabase Authの招待・ログインは隔離環境で別途確認が必要。設定から書き出したV4 JSONを任意選択し、件数確認後に取り込む。元の履歴と設定はスナップショットに保存し、カード・会話をTopic別に再構成する。同じファイルを再実行しても重複しない。
