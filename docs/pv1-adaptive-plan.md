# PV1 Adaptive Board と UI の開発計画

本番は main、PV1 の統合先は pv1/integration。PR #7 の pv1/m2-learning が個人ワークスペースの検証基点。PR #13 はそこから分岐し、Preview での検証を目的とする。

| 工程 | 現状と次の受入条件                                                                                |
| ---- | ------------------------------------------------------------------------------------------------- |
| M1   | 個人 Topic・Board・会話の保存と分離。既存アカウントの再ログインで復元できることを回帰条件とする。 |
| M2   | 右側 Tutor、Board 編集・固定例・提案確認を実装。自由質問への実モデル応答は課金承認後に確認する。  |
| M3   | 個人 Topic の手動分類と関係を Tree と Map で共有する。自動分類は保留。                            |
| M4   | 6分野の固定教材を個人演習として保存できる。問題生成と自由記述の採点は保留。                       |
| M5   | 実際の提出に基づく成績を表示。Preview で再ログイン後の記録を利用者が確認。AI の定性的評価は保留。 |
| M6   | 日本語・英語の操作、画面幅、キーボードを継続検証。残りの候補言語と全画面の視覚的検証は未完了。    |

| 工程 | 依存・今回の範囲・完了条件                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AB1  | M1/M2 の JSON に任意の教材ステップ参照を追加。ID・親リンク・配置・既存の改訂番号を利用。今後は汎用 Block の意味的な型、本文・数式内の参照、操作検証を追加し、旧データの往復保存を試験する。 |
| AB2  | AB1 の固定教材で定理→導出→証明を任意に展開。選択位置・周辺ノート・折り畳み・保存復元を実際の Preview で検証する。                                                                           |
| AB3  | AB1/AB2 の対象 ID と改訂番号に結びつけた操作を検証し、提案の差分、拒否、Undo、競合をテストする。まず固定アダプターで行う。                                                                  |
| AB4  | M3–M5 の履歴と本人が選択した概念を参照。提案の根拠と観測事実を分け、訂正・拒否を検証する。                                                                                                  |
| UI1  | 現状は旧シェルの緑系と個人画面の無彩色が混在。色・文字・間隔・フォーカスを共通化し、主要ページでコントラストと操作順を監査する。                                                            |
| UI2  | UI1 のトークンをナビゲーション・Board・演習・進捗へ適用。PC と幅390pxで操作でき、長い数式でもページ全体が横に溢れないことを確認する。                                                       |
| UI3  | AB2 の関連箇所が分かり、補足の展開後も学習者が元の説明に戻れることをマウスとキーボードで確認する。                                                                                          |
| UI4  | UI2/UI3 後の画面比較、アクセシビリティ、長文・数式の負荷試験を行う。ロゴ候補は最終採用前にレビューする。                                                                                    |

教材テキストは追加時の表示言語で保存し、その後の編集を保持する。既存ノートの書き換えや SQL 移行は不要。今回の教材は利用者が明示的に開いたときだけ追加する。保存済みの実データとブラウザーテスト用の模擬応答は区別する。課金、有料モデルの呼び出し、既存 PR のマージ、本番反映は承認対象とする。

## 個人Boardの受入確認（PR #16–17）

- AB2・UI3：個人ノートに問いを添え、その下に数式付きの解答を追加する。保存して一覧から開き直し、問いと解答の親子関係を確認する。
- UI3：開いた解答内で Esc を押す。解答の見出しにフォーカスが戻り、親の問いと隣の補足の展開状態が保たれることを確認する。
- UI1・UI2：個人ワークスペースの現在地表示、長い問いの折り返し、数式だけの補足の見出しを確認する。
- UI4：PC・モバイルの比較画像と模擬アカウントを使用したブラウザーテストを実施。実アカウントでの新しい Preview の保存・復元は別途確認する。
