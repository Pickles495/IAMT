# PV1 個人演習・知識構造 Preview

検証用Supabaseで以前の4件のマイグレーションが適用済みなら、`supabase/migrations/202611050005_practice.sql` だけを一度実行する。既存のTopic・Boardを利用し、演習・分類・関係をアカウントごとに保存する。OpenAIを呼ばずに以下を検証できる。

- 個人ワークスペース → 知識構造を探索 → 個人Topic → 分類・関係を編集。二つの個人Topicの関係、種類、理由を登録し、Mapで確認する。
- 個人演習・学習記録 → 関連する個人Topicを一つ以上選ぶ → 出題分野 → 作成。固定問題は6分野に各2問。数値・解集合を判定できる形式だけ採点する。
- 例：ガロア理論の第2問で「2」を提出する。Learning Progressで提出日・解答・結果を確認し、ログアウト後も記録が残ることを確かめる。
- 解説を開いた提出、証明、未対応形式は正解数の分母に含めない。集計は提出回数単位。絞り込んだ履歴はJSONに書き出せる。
- Boardでノートにキーボードフォーカスを合わせ、矢印キーで移動、Shift併用で大きく移動、Enterで編集する。

本Previewでは学習者による分類、定義済みの問題と決定的な集計を使う。AIによる自動分類、作問、記述採点、傾向の解釈は別途検証する。既存のデモデータと個人データはそれぞれの画面で管理する。
