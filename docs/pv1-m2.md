# M2 Preview

対象ブランチは `pv1/m2-learning`。M1のPreview用Supabaseプロジェクトに、未適用の `202611050003_board_edits.sql` と `202611050004_board_turns.sql` を番号順に適用する。既存のTopicとBoardに対し、保存用の版番号とBoard別の対話履歴を追加する。

1. Previewの `/workspaces` でログインして、TopicのBoard名を押す。
2. ノートを作成し、本文と数式を入力して保存する。背景をドラッグすると移動、ノートの右下をドラッグすると幅が変わる。
3. ノートを選び、右側のTutorで「固定例で操作を試す」を押す。このモードでは √2 に関する固定の回答を使い、モデルを呼び出さない。
4. 提案をBoardに反映し、Undo・Redoを試し、保存する。再ログインして同じBoardを開き、本文・数式・配置・対話を確認する。
5. 同じBoardを二つのタブで開き、片方から保存した後でもう片方から変更を保存すると競合になる。古いタブにある未保存の文章を控え、一覧に戻ってBoardを開き直す。

OpenAIを使った検証には、サーバー側のPreview変数 `OPENAI_API_KEY`、構造化出力対応の `OPENAI_MODEL`、`PV1_LIVE_TUTOR=1` を設定する。実行は利用費用を承認した後に限る。選択した要素、Boardの抜粋、直近の会話をモデルに送る。提案は採択して保存したときにBoardに反映される。
